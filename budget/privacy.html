🔒 隱私說明

最後更新：2026 年 10 月 16 日

你的資料只存在你自己的手機

薪資、記帳、AA 分帳、模擬持股、生日等所有資料，只存在你這台裝置瀏覽器的 localStorage。我們沒有帳號系統、沒有自己的伺服器，也不會收集、上傳或分析你的資料。

網站主機的存取紀錄

本站放在 GitHub Pages。GitHub 作為主機商，可能依其政策保留一般的連線紀錄（例如 IP 位址、瀏覽器類型、存取時間）。這些紀錄由 GitHub 管理，我們拿不到你的記帳內容。詳見 GitHub 隱私聲明。

股價資料來源

行情與除權息資料來自臺灣證券交易所（TWSE）與證券櫃檯買賣中心（TPEx）公開資料，每個交易日自動更新，可能有延遲或錯誤。

模擬學習用

存股功能是模擬，不會真的買賣，也不推薦任何個股。天機、星座內容僅供參考娛樂，非投資建議。

怎麼清除資料

① App 內「⚙️ 設定」→「清除全部資料」。
② 或在瀏覽器設定中清除本網站的資料（網站資料／Cookie）。
③ 從主畫面移除 App 圖示後，也建議一併清除瀏覽器的網站資料。
