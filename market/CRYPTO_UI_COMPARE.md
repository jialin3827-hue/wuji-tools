# 舞吉虛擬幣 UI｜現況 vs 目標風格對照

參考：使用者附的賽博龐克終端交易畫面（2026-10-31）。
現況頁：`market/crypto.html`（截圖 `/workspace/crypto-ui-now.png`）。

## 並排對照

| 面向 | 現況 crypto.html | 目標影片風格 | v1 建議 |
|---|---|---|---|
| 底色／字體 | 深色終端、等寬偏多 | 純黑＋霓虹、全等寬大寫、極密 | 收緊 padding、字級更小、全大寫標籤 |
| 色盤 | 綠／紅／黃（Binance 感） | 綠／青／紫／黃／紅霓虹發光 | 加 cyan／purple 強調、細 1px 分隔 |
| 版面 | 三欄＋下方 spark | 超密格：頂欄指標、中 3D、右 book、底 tape＋ticker | 加頂欄 LIVE／UTC／摘要；底 ticker |
| 中央視覺 | 2D 資金流向網 | 旋轉 3D 節點球 | **v1 不做**；v2 用 Three.js |
| Order book | 有，更新節流 | 極快閃爍 ask/bid | 略加快閃爍、加 Total 欄 |
| 成交帶 | 有 tape | 紅綠交錯 Time&Sales | 對齊欄位與閃爍 |
| K 線／小圖 | 主 K＋4 spark | 多個無軸迷你圖 | 保留主 K；頂部加 2～3 迷你 spark |
| 裝飾資訊 | 少 | CPU／RAM／六 agent 指標 | 可做**假裝飾**（標示模擬），勿誤導實盤 |
| 手機 | 單欄折疊 | 影片偏桌機密度 | v1 桌機優先、手機維持可交易 |

## 建議路線

1. **對照確認**（本檔）→ 你點頭後再開工  
2. **視覺 v1**（約 1～2 天）：密字＋霓虹＋頂欄＋ticker＋book/tape 閃爍強化；交易邏輯不動  
3. **視覺 v2**（可選）：中央 3D 節點網（輕量、可關）

## 刻意不做

- 1:1 複製影片假帳號／假策略全開（像詐騙盤）
- 為炫技犧牲手機可操作性
- 把裝飾數字寫成真實系統監控
