## 星等規則（確定性）

同一個生日永遠得到同一組星等與建議。規則寫在 `rating.js` 檔頭註解，計算也在該檔完成。本頁**不採用、不抄襲**任何外部網站的名次或資料。

2027 年為丁未年：天干丁火、地支未土（羊）。

星等顯示 1 到 5 顆星的位置，實際分數限制在 **2–5 星**（沿用工作室「小金庫分數卡」的原則：不給嚇人的 1 星；2 星稱為「調整期」）。標籤：5 順風、4 穩進、3 平穩、2 調整期。

### 規則 A｜有填出生年

沿用炭武吉「十二生肖小金庫分數卡」公式（內部文件 `charms/2027-zodiac-xiaojinku.md`）：

1. 生肖依民俗算法：以該年農曆正月初一為界（本頁內建 1924–2030 對照表，與犯太歲查詢頁同一份）。生日早於當年初一，算前一年生肖。
2. 「小金庫／貴人／心情」三項皆底分 3，再依年支「未」的合、沖、刑、破、害、三合、三會、值、偏沖，以及丁火對生肖本氣的十神加減。
3. 每項限制在 2–5 星。馬同時屬六合與三會，只取六合一次，避免灌分。偏沖（辰、酉）各派不同，只扣心情。
4. **本頁綜合星等 = 上述三項的中位數**。不公布名次，也不顯示 1–366 的排序。

### 規則 B｜未填出生年

改依生日月、日的西洋星座五行，對照丁火、未土（台灣常見星座分界；2/29 視為雙魚座）：

- 底分 3
- 火象（白羊、獅子、射手）或土象（金牛、處女、摩羯）+1
- 水象（巨蟹、天蠍、雙魚）−1
- 風象對應金（雙子、天秤、水瓶）0
- 若生日落在巳午未當令（立夏到立秋前，5/6–8/7）再 +1
- 同樣限制在 2–5 星

填了年份後改走規則 A，結果可能不同。頁面上會寫清楚用的是哪一套。
